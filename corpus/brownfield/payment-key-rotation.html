Rotate an expired payment-gateway API key

Created by Payments team, last modified on 2025-09-12

Replace the payment-gateway API key when it has expired or is about to expire.

When to use

Use this when the PaymentAuthFailures alert fires, or orders-api logs show "payment-gateway returned 401 Unauthorized: api key expired".

Steps

#What to doCommandExpected
1Check the key status.shopctl secrets describe payment-gateway-keyexpires_at is in the past or within 7 days.
2Confirm checkout is failing on auth.kubectl -n shop logs deploy/orders-api --since=15m401 Unauthorized lines from payment-gateway.
3Rotate the key.shopctl secrets rotate payment-gateway-keyA new key id is printed and the old key is revoked in 24 hours.
4Restart orders-api so it loads the new key.kubectl -n shop rollout restart deploy/orders-apiThe rollout completes.
5Confirm payments work again.curl -s http://orders-api:8080/healthStatus ok and payment-gateway ok.

Contacts

  • Page the payments team on-call if 401s continue after step 5.
